# Code of Conduct

This repository is part of BHIL's professional practice. Behavior here mirrors the standard expected on a client engagement.

## Standards

- **Be precise.** Vague feedback is worse than no feedback.
- **Be honest about failure modes.** A prompt that works 4/10 times is interesting; one that works 9/10 is the standard. Document which is which.
- **Don't sandbag knowledge.** If you discovered an Sref code, a moodboard pattern, or a workflow shortcut that improves output, contribute it. Hoarding craft knowledge in Slack threads or local notes is incompatible with a production practice.
- **Don't perform expertise.** Cite sources, mark inferences as inferences, and flag uncertainty.
- **Respect the brand discipline.** The four foundational rules and the brand register are not stylistic preferences; they are the contract this repository keeps with every BHIL deliverable.

## Out of scope

This is a working reference, not a community forum. Off-topic discussion, unrelated political content, and personal disputes have no place in PRs or issues.

## Enforcement

Violations are addressed directly by the maintainer. There is no formal escalation pathway for an internal repository of this size.
