# 00 · Introduction

> The Creator's Playbook for Advanced AI Image Generation.
> A 2026 production reference for intelligence-brand visuals.

This document is **Part 1** of the BHIL Field Playbook (April 2026). It establishes the operating premise that every other section in this repository inherits from.

---

## Executive summary

**Prompt quality equals image quality.** In April 2026, the ceiling on AI visual output is no longer set by the model — it is set by the specificity of the instruction feeding it. Midjourney v7, Gemini 3 Pro Image (Nano Banana Pro), GPT Image 2, and Flux.2 Pro all produce broadcast-grade output on demand. The delta between amateur and professional AI work is now almost entirely a prompting delta.

This playbook is a working reference for producing BHIL-grade visual deliverables:

- Intelligence report covers
- Framework diagrams
- Executive briefing hero images
- OSINT-aesthetic social tiles
- Persona art
- Location-intelligence renders

Every framework, parameter table, and prompt example has been tuned to the output BHIL actually ships — restrained editorial realism, data-viz-adjacent graphics, typographically disciplined covers, and the visual register of *Foreign Affairs* crossed with a Palantir field brief.

---

## Operating principle

> **No e-commerce. No creator-economy fluff. No generic "make this look beautiful" prompting.**
>
> The goal is repeatable, on-brand, defensible visuals at the speed of analytical thinking.

This is not a stylistic preference. It is the contract this repository keeps with every BHIL deliverable. If a prompt, framework, or workflow drifts toward glossy AI-default aesthetic, it is off-brand by definition and does not belong in this repository regardless of how technically polished it is.
