## How To Use

For prompt construction:

1. Identify the sub-register your project requires (per [`../docs/01-three-sub-registers.md`](../docs/01-three-sub-registers.md)).
2. Read the relevant sub-register specification. Note the palette, typography, photography conventions, and data conventions.
3. Cross-reference the exemplar library for anchor visuals.
4. Construct the prompt with the sub-register's conventions baked in.

Each prompt in [`../prompts/`](../prompts/) declares its sub-register and references the relevant specification.
