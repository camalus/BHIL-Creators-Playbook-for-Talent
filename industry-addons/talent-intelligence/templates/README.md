# Templates

Project-level brief templates for talent-industry imagery work. These complement the per-prompt patterns in [`../prompts/`](../prompts/) by establishing the project context, register declaration, compliance posture, and asset inventory that apply across an entire project.

## Files

| File | Purpose |
| :--- | :--- |
| [`candidate-dossier-template.md`](./candidate-dossier-template.md) | Project-level brief for retained-search candidate dossier work — codename, register declaration, anonymization rules, asset folder structure, confidentiality conventions. |
| [`employer-brand-spec-template.md`](./employer-brand-spec-template.md) | Project-level brief for employer brand campaigns — sub-register declaration, channel matrix, consent inventory, deliverable asset list, representation testing plan. |
| [`ai-disclosure-statement-template.md`](./ai-disclosure-statement-template.md) | Per-asset disclosure statement template referenced from [`../compliance/disclosure-standards.md`](../compliance/disclosure-standards.md). |

## How To Use

1. **Project initiation.** At the start of any imagery production project, instantiate the appropriate template by copying it to your project workspace and filling in the bracketed fields.
2. **Register declaration.** Every project declares its sub-register (A, B, or C) explicitly. Mixed-register projects require asset-level register declarations.
3. **Compliance posture.** Every project declares its compliance posture against the AI imagery policy ([`../compliance/ai-imagery-policy.md`](../compliance/ai-imagery-policy.md)) and references the applicable jurisdiction matrix ([`../compliance/jurisdiction-matrix.md`](../compliance/jurisdiction-matrix.md)) entries.
4. **Asset inventory.** The template enumerates the assets to be produced, the prompts that will produce them, and the consent / representation-testing / disclosure requirements per asset.
5. **Approval and archive.** The completed template, with all referenced asset provenance, becomes part of the five-year recordkeeping archive.
