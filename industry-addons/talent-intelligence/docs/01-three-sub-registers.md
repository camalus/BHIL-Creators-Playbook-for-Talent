# The Three Sub-Registers

The talent industry's visual register is bifurcated, not unified. A "talent" prompt that doesn't pick a sub-register reads as nothing in particular. This file is the single source of truth for which register your project is operating in.

Each sub-register has its own dedicated reference file with full visual specifications:

- Sub-register A — [`reference/sub-register-a-retained-search.md`](../reference/sub-register-a-retained-search.md)
- Sub-register B — [`reference/sub-register-b-platform.md`](../reference/sub-register-b-platform.md)
- Sub-register C — [`reference/sub-register-c-agency.md`](../reference/sub-register-c-agency.md)

This file is the executive summary.

## At a Glance

| Register | One-Line Description | BHIL Parent Brand Fit |
| :--- | :--- | :--- |
| **A — Retained-search editorial** | Foreign Affairs editorial restraint applied to executive talent | Near-perfect match — minimal adaptation required |
| **B — Talent-intelligence platform dashboard** | Agentic-AI dashboard with dark gradient meshes and glowing data | Requires explicit deviation toolkit |
| **C — Recruiting-agency editorial-illustration hybrid** | Lower-case headlines, illustration libraries, documentary daylight portraiture | Requires explicit deviation toolkit |

## Sub-Register A — Retained-Search Editorial

**Anchor firms:** Korn Ferry, Spencer Stuart, Egon Zehnder, Russell Reynolds Associates, Heidrick & Struggles.

**Visual logic:** Single-accent palette (one strong firm color plus a neutral system). Generous white space as the dominant compositional gesture. Soft documentary portraiture with a 45° single-source key light, background 1-2 stops darker than face, tight head-and-shoulders framing, eyeline at upper third, direct-to-camera gaze, tailored business attire with no pattern louder than fine pinstripe. Typography is humanist sans (Heidrick, RRA, Korn Ferry's KF Serif) or serif (Spencer Stuart's Rotis Serif Regular, Egon Zehnder's editorial display). Charts use one firm color plus one neutral; numbers are rendered very large; data plates lead with a 200pt+ percentage in firm color.

**Anchor reports / exemplars:**
- Heidrick & Struggles *Route to the Top 2025: The Ascent Redefined* — mountain/summit metaphor cover.
- Spencer Stuart 2025 US Board Index, 40th edition — serif editorial register, red-bar masthead.
- Korn Ferry Brand Experience V3 (February 2025) — "radically human" photography brief, six-degree shape system.
- Egon Zehnder × Moving Brands — Swiss/International restraint, EZ red as singular accent.
- Russell Reynolds *Global Leadership Monitor H1/H2 2025* — white-space-led data plates.

**When to use:**
- Executive search candidate dossiers and longlists.
- Leadership briefs and CEO/CXO succession deliverables.
- Board-search work and board indexes.
- Premium workforce-research reports (CEO surveys, leadership trend research).
- DEI reports for boards or institutional investors.
- Executive-grade conference materials (board institutes, exec roundtables).

**When not to use:**
- Top-of-funnel candidate marketing (use C).
- Platform vendor marketing (use B).
- Agency-side staffing materials (use C).

**BHIL parent brand alignment:** This is the natural default. The parent register (Foreign Affairs × Palantir field brief, navy `#0F1A2E` / ivory `#F5EFE3` / amber `#C9A24A` / signal-red `#A82A2E`, Canela Deck / GT Sectra Bold) maps almost directly onto retained-search editorial. Most prompts in this add-on's `01-executive-search/` and `04-workforce-reports/` categories will work with the parent BHIL profile and srefs unchanged.

## Sub-Register B — Talent-Intelligence Platform Dashboard

**Anchor platforms:** Eightfold AI, Gloat, Lightcast, Beamery, Draup, TalentNeuron (Gartner), LinkedIn Talent Insights.

**Visual logic:** Dark gradient mesh backdrops (deep purples, navy-to-black, indigo-to-black) punctuated by aqua, coral, lime, or magenta accent gradients. Glowing node graphs as the signature data motif — force-directed networks of dots and lines, often labeled with skill or role names. Choropleth maps in single-hue gradients carry the "global supply/demand" semantic load. Sankey diagrams carry talent-flow semantics. Bento-grid stat layouts (modular tiles combining a giant numeral, a delta arrow, a mini-chart, and a chip cloud) are the dominant marketing-graphic convention. AI-agent chat panels docked right are the signature UI element (Olivia, Curie, Winston, AI Interviewer all use this template).

**Brand palette references:**
- Eightfold "Infinite Workforce" — dark purple gradients with aqua/orange light streaks.
- Gloat — white minimalism punctuated by indigo and the *Loomra* orbital animation.
- Lightcast 2025 brand 2.0 — lavender-glow + coral hero.
- Beamery — navy + cyan + coral.
- Draup — dotted-grid backdrops with magenta/lime/orange icon tiles.
- TalentNeuron — deep teal + lime + coral.

**When to use:**
- Platform dashboard hero plates (marketing-site hero, product page hero).
- Vendor pitch deck imagery.
- Conference keynote backdrops (UNLEASH, HR Tech, Transform, RecFest, ERE).
- Skills graph and talent-flow visualizations.
- HR Tech and talent-intelligence vendor marketing campaigns.
- Recognition-badge layouts (Fosway 9-Grid, IDC MarketScape, Brandon Hall).

**When not to use:**
- Executive search deliverables (use A).
- Real-employee employer-brand work (use C with real photography).
- Premium workforce reports (use A).

**BHIL parent brand alignment:** Requires deviation. The parent BHIL palette is editorial-archival; sub-register B is dashboard-modern. Prompts in this add-on's `02-talent-intelligence-platform/` category use a separate `[PLATFORM PROFILE]` and `[PLATFORM SREFS]` set that should be locked per-project to the client's platform palette (e.g., Eightfold-style purple, Gloat-style indigo, Lightcast-style lavender + coral).

## Sub-Register C — Recruiting-Agency Editorial-Illustration Hybrid

**Anchor agencies and brands:** Randstad, Adecco, Robert Half, ManpowerGroup, AMS (Alexander Mann Solutions), Cielo Talent.

**Visual logic:** Lower-case sentence-case headlines (Randstad, AMS, increasingly Adecco). Custom typefaces as luxury cue (Randstad Sans, Adecco Sans, Robert Half's coral-accented serif). Photography is documentary daylight, with subjects in real workplace contexts, often with copy room around them rather than centered hero compositions. Illustration libraries function as authenticity hedges and localization tools — Randstad's "touch illustration" library of robots/rockets/compasses, Adecco's geometric chapter dividers, Cielo's "Illuminate Talent" torch motif. Single-color chapter dividers and section breaks are common; Robert Half's "squircle" image masks are a distinctive convention.

**Brand palette references:**
- Randstad — bright blue (`#0F69AF`) with sentence-case headlines and touch-illustration accents.
- Adecco — solid red (`#FF0000`) with desaturated worker cinematography.
- Robert Half — coral hero portraits with squircle masks.
- ManpowerGroup — blue choropleths and Ceros scrollytelling interactives.
- AMS — high-contrast magenta-on-black geometric data art (the most adventurous of the set).
- Cielo — sky-blue gradients and torch motif.

**When to use:**
- Career site hero imagery.
- LinkedIn recruiter campaign tiles.
- EVP visual systems and pillar treatments.
- Salary guide and compensation report covers.
- Job posting hero imagery (especially environmental, no-faces).
- Recruiting agency case studies and capability decks.

**When not to use:**
- Executive search dossiers (use A).
- Platform vendor marketing (use B).
- Premium leadership research (use A).

**BHIL parent brand alignment:** Requires deviation. The parent register is too austere; sub-register C is warmer and more illustration-friendly. Prompts in this add-on's `03-employer-brand/` category use lower-case headline language, employ illustration alternatives where the parent prompts would use photography, and accept a wider color palette than the parent system. Real photography is the gold standard for the human elements; AI-generated work in this register is largely environmental, illustrated, or typographic.

## Decision Tree — Which Register Fits

```text
Is this a deliverable for an executive search firm or a board-grade publication?
├── Yes → Sub-register A
└── No  → Continue

Is this a deliverable for a talent intelligence / HR Tech platform's marketing or product?
├── Yes → Sub-register B
└── No  → Continue

Is this a deliverable for a recruiting agency, an employer brand team, or a workforce report
that lives in a marketing context (career site, social media, salary guide)?
├── Yes → Sub-register C
└── No  → Continue

Edge cases:
- Workforce trend research from a Big Four / consultancy (Deloitte, PwC, McKinsey, BCG, Bain,
  Mercer): Use A if the artifact lives in board context; use C if it lives in marketing context.
- Recognition / award materials (Fosway, IDC MarketScape, Brandon Hall): Sub-register B.
- Conference keynote materials: Sub-register B for HR Tech / vendor context; sub-register A
  for board institutes / executive roundtables.
- DEI reports: Sub-register A for board/institutional audiences; sub-register C for
  candidate-facing communications.
```

## Mixing Registers (And Why You Probably Shouldn't)

It is occasionally necessary for a single project to produce assets in two registers — a vendor producing both a polished annual report (sub-register A) and a conference keynote backdrop (sub-register B), for example. The discipline:

- **Never mix registers within a single asset.** A dashboard hero plate that tries to incorporate retained-search editorial gravity reads as confused and inauthentic.
- **Lock the project at the campaign level, not the asset level.** Decide register per asset; don't try to harmonize two registers into a hybrid.
- **Document the register for each asset.** The deliverable spec template ([`templates/employer-brand-spec-template.md`](../templates/employer-brand-spec-template.md), [`templates/candidate-dossier-template.md`](../templates/candidate-dossier-template.md)) requires a register declaration. Honor it.
